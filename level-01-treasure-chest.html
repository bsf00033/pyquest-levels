📜 Quick Lesson: Variables & print()

A variable is a named box that holds a value. You create one with = (the “put this in the box” arrow).

# Make a box called name and put a word in it
name = "Captain Ada"
print(name)
→ Captain Ada

print() shouts whatever you put inside the parentheses to the console. You can print text, numbers, or variables — or mix them:

gems = 3
print("I found", gems, "gems!")
→ I found 3 gems!
# Or build one message with + (text only — turn numbers into text with str())
coins = 10
print("Coins: " + str(coins))
→ Coins: 10
