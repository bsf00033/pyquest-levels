📜 Quick Lesson: if / else / elif

Sometimes your code must choose. An if checks a condition. If it’s true, that block runs. Use else for the “otherwise” path, and elif (else if) for extra checks.

==equal to (compare — not the same as =) >greater than >=greater than or equal to ifrun this block when the condition is true elserun when the if (and elifs) were false elifanother check if the previous ones failed
# Unlock with the right key
key = 7
if key == 7:
  print("The gate opens!")
→ The gate opens!
# Two paths: pass or train
courage = 12
if courage > 10:
  print("You may pass")
else:
  print("You must train")
→ You may pass
# Three branches with elif
gems = 3
if gems >= 5:
  print("You are rich!")
elif gems >= 1:
  print("Enough gems")
else:
  print("Need more gems")
→ Enough gems

Remember: indent the lines under if / elif / else (usually 4 spaces). The colon : ends each header line.

What you learned:

  • if runs a block when a condition is true (use == to compare).
  • else covers the “otherwise” path when the if was false.
  • elif adds another check between if and else — great for three (or more) branches.
