📜 Quick Lesson: if / else & type edge

Types matter! In PyKémon: Water beats Fire, Fire beats Electric, Electric beats Water. Use if with == to check a matchup, and else when it’s only a normal hit.

# Water vs Fire → type edge!
my_type = "Water"
enemy_type = "Fire"
if my_type == "Water" and enemy_type == "Fire":
    print("SUPER advantage!")
→ SUPER advantage!
# Advantage multiplies damage
damage = 20
multiplier = 2
print(damage * multiplier)
→ 40
# if / else: SUPER vs normal
my_type = "Water"
enemy_type = "Fire"
if my_type == "Water" and enemy_type == "Fire":
    print("SUPER")
else:
    print("normal")
→ SUPER  (if branch — Water beats Fire)
if check a matchup
== equals
else otherwise
* multiply damage

Remember: indent lines under if / else, and end those lines with a colon :. ✨
