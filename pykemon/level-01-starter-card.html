📜 Quick Lesson: Variables make a PyKémon

A variable is a named box that holds a value. You create one with =. Strings (words) need quotes. Numbers do not.

# A name is text — use quotes
name = "Sparkybolt"
print(name)
→ Sparkybolt
# HP is a number — no quotes
hp = 60
print(hp)
→ 60

We call the type ptype because type is already a Python word. Mix variables in one print:

ptype = "Electric"
print(name, "is", ptype)
→ Sparkybolt is Electric
